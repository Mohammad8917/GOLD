# راهنمای کامل نصب و راه‌اندازی GOLD در Windows 11

این راهنما برای نصب از صفر نوشته شده است. ترتیب مراحل را رعایت کن. همه فرمان‌ها در **PowerShell** و از پوشه‌ای که مخزن را در آن دانلود کرده‌ای اجرا می‌شوند.

> **محدوده پروژه:** GOLD فقط دادهٔ XAU/USD را از Twelve Data دریافت می‌کند، تحلیل می‌کند و هشدار را به تلگرام می‌فرستد. اتصال صرافی یا کارگزاری، کلید معاملاتی، ثبت سفارش و اجرای معامله در این پروژه وجود ندارد و نباید اضافه شود.

## 1. نسخه‌های پشتیبانی‌شده Python

- **Python 3.11، 3.12، 3.13 و 3.14** در ماتریس CI پروژه روی Windows و Ubuntu آزموده می‌شوند.
- برای اولین نصب روی Windows 11، **Python 3.11.x نسخهٔ پیشنهادی و محافظه‌کارانه** است؛ دستورهای این راهنما بر همین نسخه تنظیم شده‌اند.
- از Python قدیمی‌تر از 3.11 استفاده نکن.
- اگر نسخهٔ دیگری از چهار نسخهٔ بالا را نصب داری، می‌توانی به‌جای `py -3.11` از `py -3.12`، `py -3.13` یا `py -3.14` استفاده کنی؛ نسخه‌ای را انتخاب کن که واقعاً نصب شده است.
- نسخه‌های آینده یا نسخه‌های خارج از این فهرست تا زمانی که در CI پروژه اضافه و موفق نشده‌اند، رسماً تأییدشده محسوب نمی‌شوند.

بررسی نسخه و نسخه‌های نصب‌شده:

```powershell
py --list
py -3.11 --version
python --version
```

اگر فرمان `py` شناخته نشد، Python را از صفحهٔ رسمی Windows نصب کن و گزینهٔ **Python Launcher** و در صورت نمایش **Add Python to PATH** را فعال کن. پس از نصب، PowerShell را ببند و دوباره باز کن.

- دانلود رسمی Python برای Windows: https://www.python.org/downloads/windows/
- راهنمای رسمی نصب Python در Windows: https://docs.python.org/3/using/windows.html

## 2. پیش‌نیازهای نرم‌افزاری

موارد لازم:

1. Windows 11 به‌روز و دسترسی اینترنت.
2. Python یکی از نسخه‌های پشتیبانی‌شده؛ برای شروع 3.11.
3. Git for Windows برای دریافت و به‌روزرسانی مخزن.
4. PowerShell (در Windows 11 موجود است).
5. حساب Twelve Data و API Key مجاز برای دریافت دادهٔ XAU/USD.
6. حساب Telegram، یک ربات ساخته‌شده با BotFather و شناسهٔ مقصد (Chat ID).

برای نصب این پروژه به پایگاه دادهٔ جداگانه، Docker، Node.js، Visual Studio یا نرم‌افزار صرافی نیاز نیست. وابستگی‌های Python از فایل requirements خود پروژه نصب می‌شوند.

- Git for Windows: https://git-scm.com/download/win

## 3. دریافت پروژه از GitHub

PowerShell را باز کن و دستورها را اجرا کن:

```powershell
New-Item -ItemType Directory -Force "$HOME\Projects" | Out-Null
Set-Location "$HOME\Projects"
git clone https://github.com/Mohammad8917/GOLD.git
Set-Location .\GOLD
git switch main
git pull
```

برای بررسی اینکه در ریشهٔ درست مخزن هستی:

```powershell
Get-Location
git status --short --branch
git log -1 --oneline
```

اگر قبلاً مخزن را clone کرده‌ای، دوباره clone نکن؛ وارد همان پوشه شو و `git pull` را اجرا کن.

## 4. نصب Python و ساخت محیط مجازی

در ریشهٔ مخزن:

```powershell
py -3.11 --version
py -3.11 -m venv .venv-gold
.\.venv-gold\Scripts\Activate.ps1
python --version
python -m pip install --upgrade pip
python -m pip install -r tools\gold_signal_bot\requirements.txt
```

پس از فعال‌سازی محیط مجازی، ابتدای خط PowerShell معمولاً عبارت `(.venv-gold)` دیده می‌شود. خروجی `python --version` باید Python 3.11.x باشد.

### اگر PowerShell اجرای Activate.ps1 را مسدود کرد

فقط برای پنجرهٔ فعلی PowerShell، این فرمان را اجرا کن و دوباره فعال‌سازی را انجام بده:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv-gold\Scripts\Activate.ps1
```

این تغییر فقط تا بسته‌شدن همان پنجره معتبر است؛ سیاست سراسری سیستم را تغییر نده.

### اگر نصب وابستگی‌ها خطا داد

ابتدا مطمئن شو محیط مجازی فعال است و از Python درست استفاده می‌کنی:

```powershell
python --version
python -m pip --version
python -m pip install --upgrade pip
python -m pip install -r tools\gold_signal_bot\requirements.txt
```

وابستگی‌های مستقیم فعلی پروژه در `tools/gold_signal_bot/requirements.txt` نگهداری می‌شوند؛ در نسخهٔ فعلی شامل `requests` و `python-dotenv` هستند. آن‌ها را جداگانه از سایت‌های متفرقه دانلود نکن.

## 5. ساخت کلید API در Twelve Data

1. در سایت رسمی Twelve Data حساب بساز یا وارد حساب خودت شو: https://twelvedata.com/
2. از داشبورد حساب، API Key را دریافت کن.
3. مستندات رسمی API و پشتیبانی نمادها را بررسی کن: https://twelvedata.com/docs
4. قبل از استفاده، در داشبورد ارائه‌دهنده بررسی کن که حساب و طرح انتخابی تو دسترسی لازم به نماد **XAU/USD** و تایم‌فریم موردنظر را دارد و محدودیت درخواست آن چیست.
5. API Key را فقط در فایل محلی `.env` قرار بده. آن را در GitHub، کد، تصویر، گزارش عمومی یا گفت‌وگو منتشر نکن.

محدودیت تعداد درخواست و دسترسی نماد به حساب و طرح ارائه‌دهنده وابسته است و ممکن است تغییر کند؛ به رایگان یا نامحدود بودن دسترسی فرض نکن.

## 6. ساخت ربات تلگرام و گرفتن Chat ID

### ساخت ربات با BotFather

1. در Telegram، حساب رسمی **@BotFather** را باز کن: https://t.me/BotFather
2. فرمان `/newbot` را ارسال کن.
3. یک نام نمایشی انتخاب کن.
4. یک username یکتا انتخاب کن که طبق قوانین تلگرام به `bot` ختم شود.
5. BotFather یک **Bot Token** می‌دهد. این توکن مثل رمز عبور است؛ آن را به هیچ‌کس نده و در چت یا GitHub قرار نده.
6. گفت‌وگوی خصوصی ربات تازه‌ساخته‌شده را باز کن و دکمه Start را بزن؛ یا اگر مقصد گروه/کانال است، ربات را به آن اضافه کن.

راهنمای رسمی تلگرام: https://core.telegram.org/bots/features#botfather

### پیدا کردن Chat ID

برای چت خصوصی، ابتدا به ربات خودت پیام بده یا Start را بزن. سپس با مرورگر خودت و در حالی که توکن را محرمانه نگه می‌داری، روش رسمی Bot API را اجرا کن:

`https://api.telegram.org/bot<TOKEN>/getUpdates`

به‌جای `<TOKEN>` توکن واقعی خودت را فقط در مرورگر شخصی خودت وارد کن. در پاسخ JSON، مقدار `message.chat.id` شناسهٔ چت خصوصی است. برای گروه، ربات را به گروه اضافه کن و یک پیام در گروه بفرست؛ شناسه در `message.chat.id` همان به‌روزرسانی دیده می‌شود. شناسهٔ کانال ممکن است به‌صورت عدد منفی با پیشوند `-100` نمایش داده شود.

**هشدار امنیتی:** URL بالا حاوی توکن است. آن را برای کسی نفرست، در اسکرین‌شات نشان نده و در تاریخچه یا پیام‌های عمومی ذخیره/منتشر نکن. اگر توکن افشا شد، از BotFather آن را باطل و توکن جدید بساز. ربات برای ارسال در کانال باید عضو کانال و دارای مجوز ارسال پیام باشد.

مرجع رسمی Bot API: https://core.telegram.org/bots/api#getupdates

## 7. پیکربندی فایل محرمانه .env

از ریشهٔ مخزن، فایل نمونه را به فایل محلی تبدیل کن:

```powershell
if (-not (Test-Path .env)) {
    Copy-Item .env.example .env
}
notepad .env
```

اگر `.env` از قبل وجود دارد، آن را با فایل نمونه جایگزین نکن؛ فقط مقادیر لازم را در همان فایل ویرایش کن.

مقادیر اصلی:

```dotenv
GOLD_TWELVE_DATA_API_KEY=کلید_واقعی_Twelve_Data
GOLD_TELEGRAM_BOT_TOKEN=توکن_واقعی_BotFather
GOLD_TELEGRAM_CHAT_ID=شناسه_چت_مقصد
GOLD_TIMEFRAME=15min
GOLD_POLL_SECONDS=45
GOLD_RISK_ATR_MULTIPLIER=1.5
GOLD_TP1_R=1.0
GOLD_TP2_R=2.0
SIGNAL_TTL_CANDLES=
GOLD_RETRY_ATTEMPTS=3
GOLD_RETRY_BASE_SECONDS=1
```

مقادیر بالا نمونه‌اند؛ سه مقدار اول را با مقادیر واقعی خودت جایگزین کن. از گذاشتن علامت نقل‌قول یا فاصلهٔ اضافی در ابتدا/انتهای مقدار خودداری کن.

| متغیر | کاربرد |
|---|---|
| `GOLD_TWELVE_DATA_API_KEY` | کلید دریافت داده از Twelve Data؛ الزامی |
| `GOLD_TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام؛ الزامی |
| `GOLD_TELEGRAM_CHAT_ID` | مقصد ارسال پیام؛ الزامی |
| `GOLD_TIMEFRAME` | تایم‌فریم؛ مقدار پیش‌فرض 15min. مقادیر مستندشده: 1min، 5min، 15min، 30min، 1h، 4h، 1day |
| `GOLD_POLL_SECONDS` | فاصلهٔ بررسی چرخه‌ای؛ نمونهٔ پیش‌فرض 45 ثانیه |
| `GOLD_RISK_ATR_MULTIPLIER` | ضریب ATR برای فاصلهٔ حد ضرر؛ پیش‌فرض 1.5 |
| `GOLD_TP1_R` | هدف اول برحسب R؛ پیش‌فرض 1.0 |
| `GOLD_TP2_R` | هدف دوم برحسب R؛ پیش‌فرض 2.0 و باید از TP1 بزرگ‌تر باشد |
| `SIGNAL_TTL_CANDLES` | تعداد کندل‌های اعتبار سیگنال؛ خالی یعنی پیش‌فرض یک‌روزه متناسب با تایم‌فریم |
| `GOLD_RETRY_ATTEMPTS` | تعداد تلاش مجدد برای خطاهای قابل‌بازیابی؛ پیش‌فرض 3 |
| `GOLD_RETRY_BASE_SECONDS` | زمان پایهٔ مکث retry؛ پیش‌فرض 1 ثانیه |

برای مشاهدهٔ فهرست نهایی و توضیح هر متغیر، README و `.env.example` همان نسخهٔ مخزن را ملاک قرار بده. مقادیر نامعتبر یا ناسازگار ممکن است باعث توقف برنامه شوند.

### مطمئن شو .env وارد Git نمی‌شود

```powershell
git check-ignore .env
git status --short
```

فرمان اول باید مسیر `.env` را به‌عنوان فایل ignoreشده نشان دهد. اگر این‌طور نبود، هیچ commit یا push انجام نده و ابتدا مشکل ignore را برطرف کن. هرگز محتوای واقعی `.env` را در خروجی یا تصویر عمومی نشان نده.

## 8. آزمون آفلاین پیش از اتصال زنده

با محیط مجازی فعال و از ریشهٔ مخزن:

```powershell
python -m unittest discover -s tools\gold_signal_bot -p "test_*.py" -v
python tools\gold_signal_bot\mutation_audit.py
```

هر دو فرمان باید با موفقیت تمام شوند. این تست‌ها به معنی تأیید اتصال واقعی API یا تلگرام نیستند؛ آن‌ها مسیرهای محلی و آزمون‌های خودکار را بررسی می‌کنند.

## 9. تست اتصال تلگرام و دادهٔ بازار

ابتدا تست ارسال تلگرام:

```powershell
python tools\gold_signal_bot\gold_signal_bot.py --test-telegram
```

باید پیام آزمایشی را در مقصد انتخاب‌شده دریافت کنی. اگر دریافت نشد، قبل از ادامه توکن، Chat ID، عضویت ربات در گروه/کانال و مجوز ارسال را بررسی کن.

سپس یک چرخه دریافت داده و بررسی سیگنال:

```powershell
python tools\gold_signal_bot\gold_signal_bot.py --once
```

این فرمان ممکن است به‌دلیل نبود سیگنال معتبر، پیام معاملاتی نفرستد؛ نبود سیگنال به‌تنهایی نشانهٔ خرابی نیست. خطاهای API، نماد، مجوز، سهمیه و تازگی داده را از خروجی بررسی کن.

## 10. اجرای پیوسته و توقف

برای شروع اجرای پیوسته:

```powershell
python -u tools\gold_signal_bot\gold_signal_bot.py
```

پنجرهٔ PowerShell را باز نگه دار و سیستم را به اینترنت متصل نگه دار. فقط **یک نمونه** از ربات را با همان فایل state اجرا کن. برای توقف کنترل‌شده، در همان پنجره `Ctrl+C` بزن.

برای خروج از محیط مجازی:

```powershell
deactivate
```

برای اجرای دوباره، وارد پوشهٔ مخزن شو و محیط مجازی را فعال کن:

```powershell
Set-Location "$HOME\Projects\GOLD"
.\.venv-gold\Scripts\Activate.ps1
python -u tools\gold_signal_bot\gold_signal_bot.py
```

اجرای خودکار هنگام روشن‌شدن Windows یا اجرای سرویس دائمی در این راهنمای نصب پایه تنظیم نشده است؛ ابتدا تست محلی و پایداری را با موفقیت کامل کن.

## 11. آزمون پایداری 24 تا 72 ساعته

پس از موفقیت تست‌های آفلاین، اتصال تلگرام و دریافت دادهٔ زنده، دستورالعمل دقیق پایش را در [STABILITY_TEST.md](STABILITY_TEST.md) اجرا کن. این مرحله باید روی همان Windows 11 انجام شود؛ موفقیت CI ابری جایگزین آن نیست. فایل‌های log، CSV، state و outbox/WAL را بررسی و برای عیب‌یابی نگهداری کن. پیش از انتشار هر گزارش، توکن‌ها و داده‌های خصوصی را حذف کن.

## 12. عیب‌یابی خطاهای متداول

| نشانه | مواردی که باید بررسی شود |
|---|---|
| `py is not recognized` | نصب Python Launcher، فعال بودن گزینه‌های نصب و بازکردن دوباره PowerShell |
| `No module named ...` | فعال بودن `.venv-gold` و نصب requirements با `python -m pip` |
| فعال‌سازی مسدود است | اجرای ExecutionPolicy فقط در Scope=Process طبق بخش 4 |
| API خطای احراز هویت می‌دهد | صحت API Key و فعال بودن حساب Twelve Data |
| API نماد یا تایم‌فریم را نمی‌پذیرد | دسترسی نماد XAU/USD و محدودیت طرح/تایم‌فریم در داشبورد و مستندات Twelve Data |
| HTTP 429 یا quota | محدودیت دقیقه‌ای/روزانهٔ حساب؛ از افزایش بی‌رویهٔ polling خودداری کن و اجازه بده چرخهٔ مکث/بازیابی برنامه کار کند |
| Telegram 401 | توکن اشتباه، منقضی یا باطل‌شده؛ از BotFather توکن معتبر بگیر |
| Telegram 403 یا ارسال ناموفق | ربات را Start کن، به مقصد اضافه کن و مجوز ارسال پیام را بررسی کن |
| پیام به مقصد اشتباه می‌رود | مقدار Chat ID را دوباره از پیام همان چت بررسی کن |
| هیچ سیگنالی ارسال نمی‌شود | ممکن است شرط‌های استراتژی برقرار نباشد یا کندل بسته/دادهٔ کافی وجود نداشته باشد؛ log و خروجی `--once` را بررسی کن |
| timeout یا قطع اینترنت | اتصال اینترنت، فایروال و پایداری ارائه‌دهنده را بررسی کن؛ خطای موقت لزوماً به معنی خرابی state نیست |
| برنامه سریع متوقف می‌شود | متن کامل خطای PowerShell را نگه دار؛ مسیر اجرا، فعال بودن محیط مجازی و فایل `.env` را بررسی کن |

اگر خطا را برای پشتیبانی به اشتراک می‌گذاری، فقط متن خطا را پس از حذف API Key، Bot Token، Chat ID خصوصی و هرگونه اطلاعات حساس ارسال کن.

## 13. نکات مهم دربارهٔ سیگنال‌ها و محدودیت‌ها

- سیگنال‌ها خروجی یک استراتژی نمونه‌اند و سودآوری یا درصد برد مشخصی را تضمین نمی‌کنند.
- قیمت ارائه‌شده توسط Twelve Data الزاماً با قیمت کارگزار، اسپرد، کمیسیون یا قیمت اجرای واقعی یکسان نیست.
- Entry/SL/TP محاسبات تحلیلی‌اند و سفارش واقعی نیستند.
- تحویل پیام در شرایط ابهام شبکه می‌تواند تکراری شود؛ exactly-once تضمین نشده است.
- تا پایان بک‌تست، بررسی خارج از نمونه، forward-test و آزمون پایداری، از سیگنال‌ها برای تصمیم مالی واقعی استفاده نکن.
- هیچ API Key صرافی/کارگزاری، کلید معاملاتی یا قابلیت سفارش‌گذاری به پروژه اضافه نکن.
