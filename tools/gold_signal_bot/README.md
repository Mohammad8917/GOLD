# راهنمای پوشه ربات GOLD

راهنمای اجرایی و مرجع اصلی پروژه فقط در فایل ریشه مخزن نگهداری می‌شود:

- [README.md ریشه مخزن](../../README.md)

برای جلوگیری از اختلاف مستندات با کد، این فایل عمداً راهنمای نصب یا جدول تنظیمات جداگانه‌ای تکرار نمی‌کند. همه فرمان‌های نصب و اجرا، متغیرهای محیطی، رفتار retry و سهمیه، چرخه عمر سیگنال، cursor و outbox/WAL، محدودیت‌های شروع و catch-up، بک‌تست و آزمون‌های عملیاتی باید از README ریشه خوانده شوند.

## مرجع‌های فنی همین پوشه

- [معماری ماژول‌ها](ARCHITECTURE.md)
- [ممیزی کیفیت تست](TEST_QUALITY_AUDIT.md)
- [آزمون پایداری Windows](STABILITY_TEST.md)
- [قرارداد signal-only](tests/test_signal_only_contract.py)

این فایل به‌تنهایی گواه آماده‌بودن عملیاتی، صحت سیگنال‌ها یا سودآوری نیست. برای ادعای آمادگی باید تست‌های CI، آزمون‌های محلی Windows، اتصال زنده Twelve Data/Telegram و forward-test جداگانه ارزیابی شوند.
